# Security policy

IONSTORM is a client-side browser game. It does not currently process accounts, payments, private user content, or server-side game state.

## Reporting a vulnerability

Please do not publish credentials, personal data, or an exploitable proof of concept in a public issue. Use GitHub's private vulnerability reporting flow for this repository when it is available. If private reporting is unavailable, open a minimal issue titled `Security: private contact requested` and do not include sensitive details; a maintainer will follow up through GitHub.

Reports should include the affected browser or platform, the smallest reproducible case, and the likely impact.
