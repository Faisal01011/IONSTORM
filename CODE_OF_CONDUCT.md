# Code of Conduct

IONSTORM is a small open-source project, and its contributors are expected to help keep it welcoming and technically focused.

## Expected behavior

- Be respectful and constructive.
- Explain disagreements with evidence and assume good intent.
- Welcome different levels of experience.
- Give actionable feedback about code, design, and gameplay.

## Unacceptable behavior

Harassment, discrimination, personal attacks, intimidation, unwanted contact, and publishing private information are not acceptable in project spaces.

## Enforcement

Report conduct concerns privately through the repository's GitHub contact options. The maintainer may edit, remove, or close contributions that violate this code and may restrict participation when necessary to keep the project safe and productive.
